# gdoc

Pull Google Docs into high-fidelity Markdown and HTML.

## Installation

```bash
# Development installation
make dev-setup

# Or manually:
uv venv
source .venv/bin/activate
uv pip install -e .
```

## Usage

```bash
gdoc --help
gdoc hello
```

## Development

```bash
make help          # Show all commands
make test          # Run tests
make check         # Lint + format + test
```
